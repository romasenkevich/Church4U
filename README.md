# Church4U

Единая база **канонических** слов для прославления.

## Структура

```
ФОРМАТ.txt          — описание формата .txt
проект.md           — проблемы, цели, задачи команды
песни/
  песнь-возрождения/
  заря-пробуждения/
  детские/
  детский-хор/
  молодежные/
  молодежный-хор/
  общее-пение/
  специальные/
  старший-хор/
```

В каждом `.txt` — только слова и пустые строки (без метаданных и меток куплетов/припевов).
Подробности в `ФОРМАТ.txt`.
