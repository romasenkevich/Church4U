# Church4U

Единая база **канона** слов для прославления.

Сейчас в репозитории — только утверждённый текст. Без вариантов, без «левых» переводов, без метаданных в файлах.

## Структура

```
проект.md           — проблемы, цели, задачи команды
песни/
  песнь-возрождения/
  заря-пробуждения/
  детские/
  детский-хор/
  молодежные/
  молодежный-хор/
  общее-пение/
  специальные/
  старший-хор/
```

Один файл = одна песня. Внутри — только слова и пустые строки.
