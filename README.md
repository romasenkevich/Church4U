# Church4U

Единая база слов для прославления (слайды / ProPresenter / приложения).

## Структура

```
ФОРМАТ.txt          — описание формата .txt
проект.md           — проблемы, цели, задачи команды
песни/
  песнь-возрождения/
  заря-пробуждения/
  детские/
  детский-хор/
  молодежные/
  молодежный-хор/
  общее-пение/
  специальные/
  старший-хор/
```

Формат слайдов: секции `[КУПЛЕТ 1]`, `[ПРИПЕВ]`, `[ПРЕДПРИПЕВ]`, `[МОСТ]`, `[ТЭГ]`…
Пустая строка внутри секции = новый слайд. Подробности в `ФОРМАТ.txt`.
