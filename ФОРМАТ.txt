Формат песни (Church4U / .txt)
==============================

Один файл = один вариант текста. Кодировка UTF-8.
Всё лежит в папке категории (детские/, молодежные/, …) — без вложенных папок на песню.

Имя файла (варианты одного названия)
------------------------------------
Основной:      Название.txt
Неосновной:    Название v2.txt
               Название v3.txt
  Пример: «Радость в сердце.txt» · «Радость в сердце v2.txt»

TITLE внутри файлов — одинаковый.
PREFERRED: да у основного, нет у v2/v3…
VARIANT: v1 | v2 | v3 | …

Заголовок (метаданные)
----------------------
TITLE: Название для поиска и экрана (одно и то же у всех вариантов)
CATEGORY: папка-категория
ALIASES: другие имена через |

SOURCE: сборник (Песнь возрождения / Заря пробуждения / …) или пусто:
         SOURCE:

ORIGINAL / ORIGINAL_ARTIST / ORIGINAL_LINK — если есть канон / EN / HolyChords

LANGUAGE: ru | en | be | ua | …
PREFERRED: да | нет
VARIANT: v1 | v2 | v3 | …

NOTE: любая пометка

После метаданных — строка из трёх дефисов:
---

Секции = тип куска песни
------------------------
Каждая секция начинается с тега в квадратных скобках:

  [КУПЛЕТ 1]   [КУПЛЕТ 2]   [КУПЛЕТ 3] ...
  [ПРИПЕВ]
  [ПРЕДПРИПЕВ]
  [МОСТ]
  [ТЭГ]        (редко: короткий повтор в конце / tag)
  [КОНЕЦ]      (ending / coda)
  [ИНТРО]
  [АУТРО]
  [ГОВОР]      (spoken / reading, если нужно)

Внутри секции — два режима показа из одного файла
-------------------------------------------------
Пишем текст так, будто для молодёжки: обычно по 2 строки,
абзацы разделяем пустой строкой.

  [КУПЛЕТ 1]
  Строка 1
  Строка 2

  Строка 3
  Строка 4

Теги [КУПЛЕТ] / [ПРИПЕВ] / … на экран НЕ выводятся —
только группируют текст.

РЕЖИМ «СОБРАНИЕ» (весь куплет / весь припев сразу)
  → весь текст внутри одной секции = ОДИН слайд.
  → пустые строки внутри секции игнорируются (склеиваем).
  → итог: один слайд «Куплет 1», один слайд «Припев».

РЕЖИМ «МОЛОДЁЖКА / РМС» (по 2 строки)
  → каждый абзац (блок между пустыми строками) = отдельный слайд.
  → итог: из примера выше 2 слайда куплета + … 

Два файла не нужны. Экспорт в ProPresenter выбирает режим
(сценарий служения) и либо склеивает секцию, либо режет по абзацам.

Как писать абзацы
-----------------
– В абзаце обычно 2 строки (молодёжка).
– Редко 1 или 3 — если так поётся / некуда деть.
– Не ставить пустую строку «для красоты» внутри того,
  что на молодёжке должно быть одним слайдом.

Повтор строк в тексте
---------------------
Если в оригинале «(2 раза)» — пишем строку дважды
или оставляем пометку в NOTE. Не полагаемся на магию плеера.

Порядок в файле = порядок исполнения
------------------------------------
Пишем секции в том порядке, в каком поют
(куплет → припев → куплет → припев → мост → припев…).
Если припев один и тот же — можно повторить блок [ПРИПЕВ]
или один раз написать и в NOTE указать схему: V1 C V2 C B C.

Мини-пример (один файл → два показа)
------------------------------------
TITLE: Пример
CATEGORY: молодежные
SOURCE:
---
[КУПЛЕТ 1]
Строка один
Строка два

Строка три
Строка четыре

[ПРИПЕВ]
Припев строка 1
Припев строка 2

Припев строка 3
Припев строка 4

Собрание:  2 слайда (весь куплет | весь припев)
Молодёжка: 4 слайда (по 2 строки каждый)
