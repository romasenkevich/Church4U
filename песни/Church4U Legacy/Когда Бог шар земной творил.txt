Когда Бог шар земной творил,
И собирал в созвездья звезды,
Дух Божий над водою плыл.
В шесть дней Бог мир прекрасный создал.

Шесть дней в неделе - для труда.
Спеши все сделать для людей,
А день седьмой отдай для Господа, для славы Божией.

Светило дня, светило ночи
Бог сотворил для жизни свет,
А в день седьмой
Сам Бог почил,
Так отдыхай и человек.

Шесть дней в неделе - для труда.
Спеши все сделать для людей,
А день седьмой отдай для Господа, для славы Божией.

Вокруг земли устлал лугами.
Увидел Бог: все хорошо,
Своими первыми шагами
В мир этот человек вошел.

Шесть дней в неделе - для труда.
Спеши все сделать для людей,
А день седьмой отдай для Господа, для славы Божией.
